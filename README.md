## 🚨 How to Check If a Pre Owned iPhone Is Genuine

Before buying any **second hand iPhones South Africa**, verify authenticity.

Go to Settings → General → About and confirm the device runs genuine iOS.

Open the App Store. Fake iPhones often redirect to Google Play.

Confirm that Face ID, Touch ID, cameras, speakers, and buttons function properly.

If anything feels suspicious, walk away.
